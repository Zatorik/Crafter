# PuraArena
Plugin Paper 26.3. Gladiador livre, X1 por convite, kits e restauração do inventário após a partida.

Comandos: /gladiador, /gladiador entrar, /gladiador sair, /x1 jogador, /x1 aceitar, /x1 recusar, /x1 cancelar, /arena top.

Configure mundo e coordenadas de arena em plugins/PuraArena/config.yml. A arena deve ser uma área plana, fechada e segura. Convites expiram em 60 segundos.

O GitHub Actions compila com Java 25 e publica o JAR como artifact.
